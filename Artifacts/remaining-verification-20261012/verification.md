# 남은 검증 처리 결과

2026-10-12 · CoreVersion 26.10.0.0 · 기준 커밋 4d02a54d856b982db0e002d09d23c054d7afc692

현재 가능한 검증을 추가로 수행했다. OS 키 입력을 통한 메뉴·로비·연습 전투 검증을 통과했고, 수행할 수 없는 항목은 아래와 같이 SKIP 처리했다. SKIP은 기능이나 기존 계획의 완료를 뜻하지 않는다. 이번에는 제품 소스를 추가로 수정하거나 커밋하지 않았다.

## 추가 통과 항목

Maker stop → clear_logs → refresh → build 로그 → play → OS 입력/CUA → Maker 상태 관찰·normal 로그 → stop 순서로 검증했다. OS 입력 도구의 성공 응답만으로 판정하지 않고 실제 Maker 로그와 assertion 결과를 확인했다.

| 항목 | 결과 및 근거 |
|---|---|
| OS Esc 메뉴 | 열기 IsOpen=true, 닫기 IsOpen=false. GameMenu open/close 로그 확인 |
| 메뉴 입력 차단 | 메뉴를 연 상태의 OS D 입력에서 위치 유지, 이동 요청 없음 |
| 로비 OS D/A | -27.3681698 → -26.2486000 → -27.3686008. 이동당 0.24초, 두 착지 corrected=false |
| 연습 전투 OS D/A | 기존 skill_test 자동 진입을 사용. 셀 2→3→2, 턴 1→2→3, PlayerTurn 복귀. 두 착지 corrected=false |
| 완료 상태 정리 | 클라이언트 localMove 및 서버의 이동/착지 검사 해제. 서버 승인 셀과 루트 위치 일치 |
| 저장 키 복원 | 새 Play에서 UnionProfile / RunResultLatestV1 / RunResultHistoryIndexV1 / RunResultRecordV1: 기본값과 lobby 확인 |
| Maker 로그 | 첫 라운드 종료까지 720개, 새 Play 종료까지 166개 로그 Error/Warning 0. 최종 build 로그 0 |

로비와 연습 전투의 OS 키 입력은 각 80ms 단발이다. 사람의 물리 키보드 조작, 연속·빠른 반전 전체 조합, 모든 전투맵의 화면 체감 검증으로 확대하지 않는다. 앞선 20맵 이동 검증과 전체 튜토리얼 기능 검증은 기존 기록을 유지하고 반복 실행하지 않았다.

## SKIP 처리

| 항목 | 수행할 수 없는 이유 |
|---|---|
| PC 슬롯 1→3·2→6 드래그 | Maker 화면 캡처는 가능하지만 OS 좌표 클릭 두 번 모두 noWindowsAvailable(-10005). 포인터 경로를 사용할 수 없어 드래그는 수행하지 않음 |
| PC 큐 예약 취소·재정렬 | 같은 OS 포인터 제한. 기존 클라이언트 RPC 검사는 실제 포인터 검증을 대신하지 않음 |
| PC 결과 확인·메뉴 다시 하기·패배 재도전 | 해당 버튼의 실제 클릭 불가. Esc 메뉴 열기·닫기만 별도로 통과 |
| PC 상점·기록·hover/scroll | 실제 포인터 입력 경로 불가. 기존 기능·컴포넌트 검증은 유지 |
| 일반 전술 조작만의 전체 런 | 직업/스킬 선택·결과/상점·경로 선택을 포함하는 정상 UI 입력 여정에 포인터가 필요함. 메서드 호출이나 강제 피해로 대체하여 완주로 판정하지 않음 |
| 사람의 이동·화면 체감 | 사람의 화면 관찰·물리 장치 입력 없음. 캡처와 최종 위치 로그로 궤적/카메라/이름표 체감을 확정하지 않음 |
| 모든 직업/점유 조합 실제 입력 | 직업·스킬 UI 포인터 조작 불가. 이번의 전사 연습 이동을 모든 조합 검증으로 취급하지 않음 |
| 모바일 | 연결된 실제 모바일 기기 없음 |
| 다중 계정·인스턴스 | 현재 Maker의 단일 사용자 및 client/server_main 문맥만 사용 가능 |
| 발행 환경 | 연결된 발행 테스트 문맥 없음 |
| 실제 저장·전송 장애 | 서비스 장애를 주입하는 인터페이스 없음. 기존 오프라인 실패·오래된 결과 검사는 유지 |
| 새 mLua LSP 진단 | 호출 가능한 diagnose 도구 없음. Maker build/runtime는 실제로 확인 |
| P0-05/06 Column/Value | 아직 구현해야 하는 DTO·직렬화 보완 작업. 검증 요청에서 기능을 추가하지 않았으며 구현 완료로 처리하지 않음 |
