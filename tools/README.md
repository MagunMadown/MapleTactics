# Balance Workbench

`balance-editor.html`을 브라우저에서 열고 `RootDesk/MyDesk/03_Data` 폴더를 선택하세요. 별도 설치나 서버·외부 전송이 없습니다.

- 구형 유니온 6개는 접힌 별도 목록에서 읽기 전용으로 열립니다. 호환·환급 데이터를 삭제하지 않습니다.
- 기본키는 명시적 등록값입니다. 두 유니온 레벨 테이블은 ID + Level 복합키입니다.
- 컬럼 설명에서 실제 참조·미사용·화면 미반영을 구분합니다. 이름 기반 idref 추론은 없습니다.
- 수정 후 전체 검사를 통과해야 현재 CSV를 다운로드할 수 있습니다. 원본 덮어쓰기는 하지 않습니다.
- CSV의 BOM·개행·따옴표·열 순서를 보존합니다. 편집하면 필요한 따옴표만 재직렬화합니다.
- 미등록 테이블은 읽기 전용입니다. 명시된 참조만 검사하므로 전체 게임 검증 성공을 의미하지 않습니다.
- Maker Refresh 후 콘텐츠 게이트와 실제 플레이 검증을 실행하세요.

검증: `node --test tools/balance-schema.test.cjs`

브라우저 화면·파일 선택 동작은 자동화 보안 정책으로 확인하지 못했습니다. CSV 모듈과 스크립트 구문은 Node 테스트로 검증합니다.

# Balance Studio

`balance-studio.html`은 위 Balance Workbench와 별개인, 밸런스를 "보면서" 조정하기 위한 도구입니다. 같은 `RootDesk/MyDesk/03_Data` 폴더를 엽니다.

- **대시보드**: 직업별 스킬 수·평균 피해·평균 쿨다운·턴당 기대치, 직업별 특수 효과 분포, 지역별 몬스터 수·평균 HP/공격력, 보스 목록.
- **밸런스 뷰**: 스킬·몬스터를 카드/리스트로 보고 수치를 바로 수정, 스킬 비교, 몬스터 패턴 상세.
- **노드맵**: `NodeDefinitions`의 런 진행 그래프.
- **데이터 에디터**: 46개 CSV 원본 편집(표/인스펙터), 참조 이동, 영향 분석.
- **RUID 미리보기·변경**: MSW 리소스 검색 API로 이미지를 보여주고, 검색/비슷한 리소스로 바꿀 수 있습니다. 이 기능만 인터넷을 사용하며 상단 🖼 버튼으로 끌 수 있습니다.
- **스킬 강화 경로**: 스킬 카드마다 "강화하면 → 다음 스킬" / "← 강화 전 스킬"을 피해·쿨·사거리 변화와 함께 보여 주고, "보기"로 그 스킬로 이동합니다. 선택 목록에서 강화 대상·강화 원본을 바로 바꿀 수 있고, 게임 규칙(강화 후보 1개)에 맞게 기존 연결은 자동으로 풀리며 다른 Tier 스킬을 고르면 Tier도 함께 맞춥니다(되돌리기 한 번으로 취소). 검색은 강화 계열 전체를 같이 찾습니다(예: "브랜디쉬" → 브레이브 슬래시도 표시). 게임의 강화 규칙(같은 직업 표 안에서 후보 정확히 1개, Tier = 원본 + 1)을 어기면 카드와 에디터에 오류로 표시합니다.
- **스테이지 탭**: 스테이지별 칸 수·시작 칸·클리어 골드, 웨이브(시작 조건·수·동시·강제 턴·풀), 그 웨이브에 실제로 나올 수 있는 후보와 확률(풀 가중치 편집), 보스 페이즈별 증원 설정, 1웨이브 등장 칸 미리보기를 한 화면에서 고칩니다.
- **경제 · 드롭 탭**: 노드 그래프의 모든 경로를 따라 상점에 도착할 때의 기대 골드(구간·누적)를 그 상점의 가장 싼 유물 값과 비교합니다. 확정 스테이지 보상 + 웨이브 몬스터 × 풀 가중치 × 드롭 기대값으로 계산하며(게임 코드와 같은 규칙, 유니온 메소·드롭률 보너스 입력 가능), 보스 증원·소환·유물 효과·지출은 넣지 않습니다. 아래 **드롭 규칙**은 `EnemyDropDefinitions`를 아이템 × 일반/보스로 묶어, 규칙 하나를 고치면 그 값을 쓰는 행 전부가 한 번에 바뀝니다(예외 행은 따로 표시·편집).
- **처치 계산 탭**: 직업 스킬로 지역 몬스터를 몇 번 써야 잡는지, 몬스터의 가장 센 스킬에 직업별로 몇 번 버티는지 표로 보여 주고, 피해·HP를 그 자리에서 고칩니다(타격당 추가 공격력·방어력 입력).
- **스킬 테스트 맵 결과 가져오기**: 게임 안 스킬 테스트 맵(I 패널)에서 내보낸 `[SkillTestExport]` 로그를 붙여넣으면, 바뀔 값과 현재 CSV 값을 비교해 보여 주고(테스트 이후 CSV가 따로 바뀐 칸은 "확인 필요") 선택한 값을 한 번에 적용합니다.
- **되돌리기 · 변경 내역**: 모든 편집을 Ctrl+Z / Ctrl+Shift+Z로 되돌리고 다시 적용합니다(한 번에 여러 칸을 바꾼 작업은 한 단계). "변경 내역"은 마지막으로 불러오거나 저장한 뒤 바뀐 칸을 표별로 보여 주고, 칸 단위·표 단위로 되돌릴 수 있습니다.
- **효과·패턴 카탈로그**: 스킬 효과 종류(빙결·다단히트·자기 이동 등), 대상/조건/대상 지정, 적 패턴 행동·조건을 선택 목록으로 고르고, 효과마다 `Value`/`ParameterA`/`ParameterB`가 무슨 뜻인지에 맞는 입력(타수·턴·이동 방식·표시 이펙트 RUID 등)이 나옵니다. 효과를 바꾸면 나머지 칸이 그 효과에 맞게 자동 정리되고, 게임 검증기와 같은 규칙으로 바로 오류를 표시합니다. 규칙은 파일 안 `#vocabCatalog` JSON에 게임 코드 기준으로 정리돼 있습니다.

## 새 효과·패턴이 추가되면

툴은 폴더를 열 때 `03_Data/Repositories`의 검증기 코드와 CSV 값을 읽어서, 카탈로그에 없는 새 값도 선택 목록에 "⚠ 카탈로그 미등록"으로 바로 보여주고 상단에 안내를 띄웁니다. 설명·전용 입력·검증까지 붙이려면 `#vocabCatalog`에 항목을 추가하세요. 빠진 값은 아래로 확인합니다(누락이 있으면 exit 1).

```bash
node tools/check-balance-vocab.cjs
```

이 규칙은 `AGENTS.md`(PROJECT RULES)에도 적혀 있어서, AI 도구로 새 효과를 추가할 때 카탈로그도 같이 갱신하도록 안내됩니다.

`file://`로 열면 읽기 전용(저장은 테이블별 다운로드), `http://localhost`에서 Chrome/Edge로 열면 폴더에 바로 저장합니다. 저장 후 Maker Refresh와 `_ContentValidatorLogic:ValidateAllContent()`로 교차 확인하세요.
