스킬 데미지, 몬스터 패턴, 스테이지 구성 등 밸런스 CSV를 표 형태로 안전하게 편집하는 도구입니다.

RootDesk/MyDesk/03_Data 폴더를 열면, 폴더 안의 모든 .csv 파일을 표 형태로 불러옵니다. ID 참조, 불리언, 숫자, |로 구분된 목록 컬럼을 자동으로 인식해서 입력 방식과 실시간 유효성 검사를 제공합니다.

폴더 열기 (읽기/쓰기)는 Chrome/Edge에서 https:// 또는 http://localhost로 이 파일을 서빙했을 때만 동작합니다 (예: 이 폴더에서 python3 -m http.server 실행 후 http://localhost:8000/…로 접속 — 터미널에 찍히는 http://[::]:8000이나 0.0.0.0, 내부 IP 주소로는 저장이 막힙니다). file://로 직접 연 경우에는 폴더 열기 (읽기 전용, 대체 모드)를 사용하세요 — 이 경우 저장은 테이블별 파일 다운로드로 대체됩니다.

열 추가 · 이름 변경 · 삭제, 새 테이블(데이터셋) 만들기도 이 도구 안에서 가능합니다 (각 테이블 헤더의 + 열 추가 / 열 이름 옆 ✎ · × 버튼, 왼쪽 메뉴 원본 표 화면의 + 새 테이블 만들기). 다만 열 이름을 바꾸거나 지우면 그 컬럼을 이름으로 참조하는 .mlua 코드가 있을 경우 함께 고쳐야 합니다 — 이 도구는 코드까지 찾아 고쳐주지는 않습니다. 저장 후에는 Maker에서 refresh 후 _ContentValidatorLogic:ValidateAllContent()를 실행해 서버 측 검증과 반드시 교차 확인하세요.
