# 스킬 매트릭스 개편

## 구현

- 로비 직업 선택과 유니온 상점 사이에 `스킬 강화 · 코어 연구원` NPC 배치. 마우스/터치 및 가까이에서 상호작용 키로 같은 강화창을 연다.
- 청회색 세로형 패널을 사용한다. 직업 탭은 없으며 로비 직업 선택에서 고른 직업의 강화 가능한 스킬만 하단에 표시한다.
- 스킬 선택 전 상단은 비어 있다. 하단 슬롯을 선택하면 중간 T1→T2 트리와 상단 전후 애니메이션·범위 칸 표시를 갱신한다. 기존 증강 화면의 프레임 크기 보정/취소 기능을 재사용한다.
- 범위 칸에서 노란색은 내 위치, 파란색은 대상 범위다. FIRST_ENEMY_FORWARD는 범위 내 첫 적 1명이라는 설명을 별도로 표시한다.
- 기존 데이터의 유효한 1→2차 계승 17개를 각 30 유니온 코인으로 영구 해금한다. 힐의 과거 `heal_ii` 행은 기존 충전 규칙에 따라 제외한다.
- 기존 유니온 보상 수급을 유지하며, 코인과 해금 소유권을 동일 프로필의 잠금/CAS 저장으로 함께 반영한다. 기존 스키마 5 저장은 `SkillTree`가 없으면 빈 해금 상태로 읽는다.
- 새 모험 출발 시 해금 목록을 캡처한다. 시작 스킬과 새 스킬 보상에 같은 계승 규칙을 적용한다. 진행 중 모험의 스킬은 로비 구매로 바뀌지 않는다.
- 인게임 스킬 강화 보상은 랜덤 증강이다. 기본/계승 스킬 모두 스킬당 최대 4회. 힐 충전 증강도 1회를 사용한다. 판매 빈자리 보충은 기존 새 스킬 보상 동작을 유지한다.
- 기존 일반·히든 증강을 재사용하며, 누적 증강 설명을 모두 표시한다.

## 검증

- Maker Refresh 및 build 로그: 오류 0. 기존 인자 개수 경고 3건 확인.
- Play에서 NPC 생성과 위치, NPC 마우스 클릭 → 강화창 열림 확인.
- 서버의 메모리 테스트 프로필로 구매·잔액 차감·중복/잔액부족/오래된 요청 거부·프로필 검증/복제 확인. 실제 사용자 코인과 저장 데이터는 테스트로 변경하지 않음.
- 임시 엔티티에서 기본 브랜디쉬 증강 4회 성공, 5회 거부, 계승 해금 스냅샷으로 브레이브 슬래시 시작, 새 모험 증강 초기화 확인. 임시 엔티티 제거.
- 저장소에 실제 구매 후 재접속하는 테스트는 수행하지 않음.

## 조정 지점

- 가격: `SkillTreeServiceLogic`의 `30 * (SkillTier - 1)`.
- 계승 연결: 직업별 SkillDefinitions의 `BaseSkillId`와 `SkillTier`.
- 증강 상한: `PlayerRunAugmentComponent.MaxSkillAugmentStages`.
- 초기 NPC 외형은 기존 로비 NPC 애니메이션에 청색 색조를 적용한 형태다.
