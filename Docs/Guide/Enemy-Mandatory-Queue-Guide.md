# 적 스킬 큐 등록 규칙 (2026-09-22)

- `TileId`가 있는 적 행동은 최소 1턴의 큐 등록을 거쳐야 한다. 기존 CSV의 `EnemyQueueTurns=0`도 런타임에서는 1로 보정한다. 신규 데이터는 1 이상으로 설정한다.
- `QUICK`은 더 이상 장전 시간을 0으로 만들지 않는다. 기존 연출 속도 특성은 유지한다.
- `EnemyActionPlanComponent.ReplacePlan`에서 최소 장전을 보장하고, `TryBeginCurrentAction`에서도 미등록 스킬 실행을 거절한다.
- 일반 공격은 `INSERTING → TRACKING → ATTACK_READY → EXECUTING` 순서다. 큐 등록 턴에는 공격하지 않는다.
- 특수 행동(별도 예고, 캐스팅 시작, 돌진, 착지)은 `INSERTING → PREPARED → EXECUTING` 순서다. 각 패턴 행이 별도 계획이므로 캐스팅 시작과 후속 공격은 각각 큐 등록을 거친다. 기존 캐스팅 유지 턴과 쿨타임은 별도다.
- 장전을 끝낸 특수 행동은 `PREPARED` 상태에서도 아이콘을 표시한다. 스킬 없는 후퇴 행동에는 소비한 스킬 아이콘을 남기지 않는다.
- 좀비버섯과 화난 불가사리는 별도 `TELEGRAPH_TILE` 행을 제거하고 일반 공격 큐의 범위 예고를 사용한다. 좀비버섯의 별도 후퇴 행도 제거해 공통 공격 후 후퇴와 중복되지 않게 했다.
- 적의 자발적 한 칸 이동은 이동 연출 전에 이동 방향을 바라본다. 플레이어 이동과 강제 밀치기의 방향 규칙은 변경하지 않았다.

## 검증

- Maker에서 실제 몬스터를 생성하고 플레이어 턴 명령으로 두 적 모두 장전 1/1, 공격 준비, 이후 턴 공격 실행 로그를 확인했다.
- 장전 전 실행 요청 거절 및 빌드 Error 0을 확인했다.
- 모든 보스 특수 패턴의 전체 회귀 플레이는 아직 수행하지 않았다. 특히 별도 예고·캐스팅·착지의 추가 장전 턴은 밸런스 확인이 필요하다.

### 특수 행동 회귀 검사

- 장전 완료 후 특수 행동까지 `TRACKING`으로 들어가 실행이 막히는 버그를 재현하고 수정했다. `AdvanceQueueTurn`에서 일반 공격만 `TRACKING`, 특수 행동은 `PREPARED`로 전환한다.
- Maker의 실제 컴포넌트로 `CAST_INTERRUPTIBLE`, `TELEGRAPH_TILE`, `CHARGE_FORWARD`, `BOSS_JUMP_TELEGRAPH`, `BOSS_LAND_OPPOSITE` 각각 장전 전 실행 거절, 장전 후 실행 허용, 완료 전환을 확인했다. `QUICK` + 장전 설정 0으로도 생략되지 않는다.
- 캐스팅 1회 타격 중단 및 중단된 스킬의 실행 거절을 확인했다.
- 포장마차 2페이즈를 테스트 초기 상태로 설정한 뒤 실제 턴 명령으로 캐스팅 시작(9턴), 레이저 실행 성공(12턴), 이후 전투 진행을 확인했다.
- 빌드 오류 0. 점프·돌진의 실제 이동/충돌 연출 전체를 플레이한 검사는 아니며, 해당 부분은 큐 상태 전이 검사 범위다.
