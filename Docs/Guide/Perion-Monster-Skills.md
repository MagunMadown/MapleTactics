## 의도적으로 구분한 부분

- 주니어 부기의 원작 상태이상 전체를 복제한 것은 아니다. 봉인만 대표 능력으로 구현했다. 암흑·허약·경험치 저주는 이번 범위에서 구현하지 않았다. 현재 전투에 없는 명중률/물리 점프/경험치 체계를 임의로 만들거나 피해로 바꾸지 않았다.
- 부기는 봉인 이후 근접 몸통박치기→후퇴로 이어진다. 기존 `region_06_jr_boogie` 정의를 공유하므로 슬리피우드의 같은 몬스터에도 적용된다. 다크 드레이크 등 다른 몬스터가 공유하던 `sleepywood_curse_shot_effects`는 변경하지 않았다.
- 지휘관의 빠른 전후 이동과 **다른 적이 없을 때 소환 / HP 50% 이하에서 사병·장교·머미독 동시 소환**은 사용자가 요청한 커스텀 보스 규칙이다. 원작 기술이라고 주장하지 않는다.
- 독안개는 원작의 지속 피해 지역을 보드 칸으로 옮겼다. 생성 즉시 피해를 주지 않아 이동으로 탈출할 기회가 있다. 같은 지휘관의 안개는 중첩하지 않는다. 보스 사망/전투 초기화/맵 세션 종료 시 안개와 표시를 제거한다. 정화는 캐릭터 봉인을 해제하며 바닥의 안개를 없애지는 않는다.
- 기존 바닥 경고 표시와 상단 안내문으로 독안개 범위를 표시한다. 새 안개 그래픽 에셋은 추가하지 않았다.
- 속성 약점/저항은 공격 기술과 구별되는 별도 전투 규칙이므로 이번 변경에 넣지 않았다.
- 기존 기술 ID `commander_heavy_cleave*`는 참조 호환성을 위해 유지하고 표시 이름·거리·모션을 기마 근접 공격으로 변경했다.

## 구현 및 검증

- `EnemySkillDefinitions.csv` / `SkillEffectSteps.csv` / `EnemyPatternSteps.csv`: 기술·효과·패턴.
- `BattleUnitComponent`: 동기화된 봉인, 정화, 만료, 전투 시작 초기화.
- `BattleSessionComponent`: 서버 명령 차단, 독안개 생명주기와 피해, 적 강화 만료, 특수 기술별 모션.
- 기존 `EffectRouterLogic` / `ContentValidatorLogic` 확장. 신규 스크립트·모델·UI 에셋 없음.
- HUD: 봉인 안내, 위험 칸 표시, 클라이언트 버튼 상태. 최종 판정은 서버에서 다시 확인.
- 추출한 실제 Lua 메서드의 모의 환경 테스트와 기존 페리온 회귀 검사 사용. **Maker refresh/play/logs 도구가 연결되지 않아 실제 빌드·게임플레이·모션 확인은 미실행**이다.

Maker에서 확인할 항목: 봉인 예고→적중→기술 비활성→이동/정화 후 해제, 호그 강화 모션 및 추가 피해, 독안개 생성·회피·2회 만료·지휘관 사망 즉시 제거, 보스 반피 전후 소환, 기존 피격/사망 연출.
