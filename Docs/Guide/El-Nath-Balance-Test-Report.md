# 엘나스 전투 밸런스 검증

기준: 2026-10-20, `feat/jjr/el-nath`. 대상은 독립 테스트 중인 엘나스 7-1~7-6이다.

## 테스트 조건

- Maker Play의 실제 전투 런타임을 사용한다. 단순 수치 시뮬레이션이나 F8 강제 클리어가 아니다.
- 공용 테스트 허브의 검증된 시작 경로로 진입한다. 전사, NORMAL, HP 10,
  브레이브 슬래시 / 디바인 차지 / 라만차 스피어 3개, 나머지 슬롯은 비운다.
- 세 스킬은 현재 CSV의 2단계다. 유물·스킬 증강·추가 재화를 임의 지급하지 않는다.
- 전투 중에는 HUD가 사용하는 `QUEUE_TILE`, `EXECUTE_QUEUE`, `MOVE`, `TURN`, `UTILITY` 명령만 보낸다.
  전사의 기존 새크로생티티(한 적 턴 피해 무시, 쿨 4턴)는 사용할 수 있다.
- 직접 HP 변경·직접 ApplyDamage 호출·강제 승리·쿨타임 초기화·적 위치 변경·타이머 생략은 사용하지 않는다.
- 테스트 정책은 현재 보이는 적 큐/방향/위치/스킬 정보를 읽고 명령을 고르는 자동 플레이어다.
  따라서 클리어 가능성의 재현 증거이며 일반 사용자의 첫 플레이 성공률이나 체감 난이도 측정은 아니다.
- 스테이지별 NEW_RUN이므로 시작 HP는 매번 10이다. 지역 연결·상점·REST·보상 선택을 포함한
  연속 캠페인 밸런스는 이번 테스트와 구분한다.

## 데이터 기준선

| 적 | HP | 피해 / 주요 패턴 |
|---|---:|---|
| 주니어 예티 | 6 | 전방 1칸 피해 1 |
| 페페 | 4 | 전방 2칸 눈덩이 피해 1, 쿨 3. 근접 대체 공격 |
| 예티 | 8 | 근접 피해 2. 전방 2칸 강타는 1턴 예고, 쿨 3 |
| 예티와 페페 | 9 | 근접 피해 2. 처치 후 HP 4 페페가 같은 칸에 분리 |
| 스노우맨 | 36 | 근접 2 / 돌풍 2+동상 / 전 보드 눈보라 3, 쿨 5, 1타 중단 |

| 플레이어 스킬(2단계) | 직격 피해 | 대상 | 쿨 |
|---|---:|---|---:|
| 브레이브 슬래시 | 3 | 전방 1~2칸 모든 적 | 4 |
| 디바인 차지 | 4 | 전방 1~2칸 모든 적 | 4 |
| 라만차 스피어 | 3 | 전방 1~3칸 중 첫 적 1명 | 4 |

추가 테스트의 1단계 구성은 `brandish|divine_swing|spear_pulling|||`이다.
각 직격 피해는 모두 2, 쿨타임은 각각 3/3/4턴이다. 직업 방어는 동일하게 사용할 수 있다.

피해 로그의 최종 값은 남은 HP로 제한된다. 예를 들어 HP 3인 적에게 디바인 차지를 쓰면
실제 감소량은 3이며, CSV의 피해 4가 무시된 것이 아니다. 전사 방어 중 적 피해 0도 정상이다.

### 해석

현재 2단계 전사 스킬 3개와 방어 능력으로 여섯 전투의 클리어 경로가 존재한다.
일반전에서는 방어 능력과 거리 유지가 강력했고 보스전은 실제 HP 4를 잃었다.
이 결과만으로 기본 1단계 스킬·무방어 플레이·전 직업·연속 6연전이 쉽다고 판단하지 않는다.
7-5의 긴 턴 수에는 자동 정책의 과도한 회피가 포함되어 있다. 이를 이유로 적 HP를 임의로 낮추지 않았다.

## 특성과 범위

엘나스의 실제 Wave → Pool → EnemyDefinition → 사망 후 후속 적을 따라 검사한다.
현재 주니어 예티·페페·예티·예티와 페페·스노우맨은 모두 `TraitIds`가 비어 있다.
HEAVY(밀치기 저항), AGGRO(공격 후 전진), QUICK(장전 단축) 부여는 없다.
회귀 검사에서도 이 세 특성의 재유입을 금지한다. 다른 지역의 특성은 별도 제거 범위다.

| 조건 | 결과 | 남은 HP | 마지막 턴 | 처치 |
|---|---|---:|---:|---:|
| 전사 7-1 / 시드 7102 / 시작 큐 3개 장전 후 일괄 실행 | Victory | 10/10 | 19 | 4 |
| 전사 7-5 / 시드 7103 / 1단계 스킬 3개 | Victory | 5/10 | 81 | 11 |

| 마법사 7-5 / 시드 7102 | 미실행: JOB_LOCKED | - | - | - |
| 마법사 7-6 / 시드 7102 | 미실행: JOB_LOCKED | - | - | - |

테스트 계정의 직업 잠금은 변경하지 않았다. 마법사 행을 성공한 전투로 계산하지 않는다.

후속 기능 검증에서 Maker 테스트 허브 한정 직업 잠금 예외를 추가했다. 이후 잠긴 마법사의 7-1 기본/커스텀
시작·스킬 피해는 별도로 확인했지만, 위 미실행 행을 마법사 전체 스테이지 클리어로 바꾸지는 않는다.
설정과 검증 범위는 [테스트 시작 가이드](Battle-Test-Loadout-Guide.md)를 참고한다.

실제로 전투한 9회는 **Victory 8회 / Defeat 1회 / 진행 정지 0회**다. 두 마법사 시나리오는 별도 미실행이다.
1단계 보스전에서도 2페이즈·캐스팅 중단·눈보라 최종 피해 3(`8 → 5`)·정상 패배까지 진행됐다.
이 1회 패배는 기본 스킬로 절대 클리어할 수 없다는 증거는 아니다. 자동 정책의 한계와 시드 차이가 있으므로
강화 효과의 차이가 큰지 검토할 추가 밸런스 표본으로 남긴다. 엘나스를 후반 지역으로 사용하는 경우와
무강화 기본 스킬만으로 쉽게 잡게 하는 경우는 서로 다른 목표다. 아직 이 목표를 확정하지 않아 HP/피해를 임의 변경하지 않았다.

자동 스크립트의 첫 쿨타임 거절 검사 중 직업 유틸을 일반 스킬로 잘못 보낸 1건은
`UNKNOWN_SKILL`로 정상 거절됐다. 검사 스크립트를 소유 일반 스킬 목록만 읽도록 고친 뒤
`COOLDOWN_ACTIVE`와 턴 불변을 다시 확인했다. 제품 코드 오류로 분류하지 않는다.

## 확인한 동작

- 실제 피해 로그 205건의 감소량과 HP 전후 차이가 일치했다. CSV 피해 및 남은 HP 제한과의 불일치는 0건이었다.
  1단계 스킬 피해 2와 2단계 스킬 피해 3/4/3이 정상 적용됐다. 활성화된 직업 방어의 피해 0은 정상 경로로 구분했다.
- 시드 7102의 7-1에서 큐 3개를 채워 실행했다. 1번 스킬 피해 → 2번 스킬로 처치 → 3번 해소 →
  `QUEUE_COMPLETE` → 다음 웨이브 순서였다. 처치 때문에 적 행동이 큐 사이에 끼어들지 않았다.
- 쿨타임 중 소유한 일반 스킬을 다시 장전하면 `COOLDOWN_ACTIVE`로 거절됐고 턴 번호가 바뀌지 않았다.
- 예티와 페페는 같은 칸의 새 페페로 분리됐고, 페페까지 처치한 뒤에만 Victory가 나왔다.
- 보스의 캐스팅 시작·1타 중단·미중단 실행 경로를 관찰했다. 이번 전사 클리어에서 미중단 눈보라의
  최종 피해 0은 직업 방어 효과가 활성화된 상태의 결과다. 이를 눈보라 피해 누락으로 해석하지 않는다.

## 판정 범위

런타임 오류, 턴 정지, 큐 실행 순서, 실제 피해, 쿨타임, 웨이브·보스 페이즈·페페 분리를 확인한다.
지역 Node를 아직 연결하지 않아 발생하는 `STAGE_NODE_NOT_FOUND` 경고는 별도로 구분한다.
기존 공통 피격·사망 연출의 전체 감사나 모든 직업·시드·승천 난이도의 무결성을 인증하지 않는다.

분리 후 준비 커서가 비었을 때 `compatibility cursor missing; selecting frozen plan` 경고가
1건 있었지만 공통 복구 경로로 진행했고, 해당 전투의 페페 처치·최종 승리까지 확인했다.
따라서 이번 결과는 경고 0건이라는 의미가 아니다. 진행을 막는 런타임 오류나 턴 정지는 관찰하지 못했다.

최종 확인에서 Maker 빌드 오류 0건, 런타임 오류 0건이었다. 빌드에는 기존 `IsPCPlatform` 폐기 예정 경고가
1건 남아 있다. 데이터/참조 검사 106개와 Balance Studio vocabulary 검사는 모두 통과했다.

공용 테스트의 커스텀 스킬은 영구 지급하지 않고 랭킹에서 제외되지만, 몬스터 도감 처치 관찰까지
일괄 차단하는 모드는 아니다. 테스트 중 새 몬스터 발견 기록이 저장될 수 있으므로
`Battle-Test-Loadout-Guide.md`의 저장 범위 설명도 함께 참고한다.

## 다시 테스트하기

1. `battle_test_hub`에서 시작하고 전사 / NORMAL / 시드 7101을 선택한다.
2. 커스텀 스킬 사용을 켜고 브레이브 슬래시·디바인 차지·라만차 스피어를 각각 2단계로 지정한다.
   나머지 슬롯은 비운다. 7-1~7-6을 각각 새 런으로 시작한다.
3. 일반 장전·실행·이동·방향 전환·직업 방어만 사용한다. 강제 클리어는 이 검증에서 제외한다.
4. 7-4/5는 탑승형 처치 후 분리된 페페까지 잡아야 승리하는지 확인한다.
   7-6은 캐스팅 중 한 번 맞히면 중단되고 다음 패턴으로 진행하는지 확인한다.
5. 데이터 검사는 `node --test tools/balance-schema.test.cjs tools/el-nath-content.test.cjs`와
   `node tools/check-balance-vocab.cjs`를 실행한다. 현재 106개 검사와 vocabulary 검사가 통과했다.
