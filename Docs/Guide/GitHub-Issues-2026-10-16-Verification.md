## 변경

- #143: 기존 랭킹 기획의 동일 조건 완주 기록, 적은 턴 → 적은 피격 정렬을 유지한다. 기록 창을 84% 크기로 줄이고, 스킬과 증강 탭을 분리했다. 스킬 증강에는 원본 스킬 아이콘, 증강 단계 및 효과를 표시한다.
- #145: 막힌 칸이라는 클라이언트 예측 후 서버가 이동을 승인하면 공통 이동·홉을 처음부터 한 번만 재생한다. 거절 시에는 반동만 한 번 재생한다. 로비와 전투의 공통 이동 경로를 유지한다.
- #156: 적 공격 아이콘을 근접/원거리로 통일하고 봉인·밀기·당기기·교대·돌진·소환·충전·예고·방어 표식을 구분한다. 부기 봉인의 지정 아이콘을 유지한다.
- #159–161: 몬스터 고정 피해 감소와 승천 HP 보너스를 EnemyDefinitions CSV로 이동했다. Balance Studio는 첫 타 보너스, 후속 고정 1 피해, 타격별 감소 및 피해 0의 처치 불가를 계산한다. 조건부 효과는 단순 처치 계산에서 제외한다.
- #162: 스킬 정의·효과와 적 패턴을 데이터 테이블별로 인덱싱한다. 반환 복사, 실시간 테스트 오버라이드, 데이터 교체 및 생명주기 초기화를 유지한다.
- #163: HUD 입력 변경을 DTO 생성 전에 검사하고 적 계획 파싱 결과와 표시용 스냅샷을 재사용한다. 실제 입력 검증은 최신 상태를 조회한다.
- #164: FaustSummonComponent를 BossSummonComponent로 변경했다. 커맨더와 다일 모델의 누락된 소환 컴포넌트 연결 및 이전 이름의 값을 복구했다. 페리온 가이드를 현재 데이터와 실제 화상 처리에 맞췄다. codeblock은 Maker 새로고침으로 생성했다.
