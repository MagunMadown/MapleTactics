# 보스 반대편 점프 제작 가이드

## 목적

1차 머쉬맘 보스가 한 방향 밀치기만 반복해 플레이어를 확정적으로 구석에 가두지 않도록 한다.
모든 직업은 기본 이동으로 대응할 수 있고, 직업 능력은 더 효율적인 대응 수단으로만 사용한다.

## 패턴 계약

```text
BOSS_JUMP_TELEGRAPH
→ 플레이어 대응 턴 동안 보스 공중 상태
→ BOSS_LAND_OPPOSITE
→ 공격/밀치기
→ MOVE_AWAY 후퇴
```

- `BOSS_JUMP_TELEGRAPH`와 `BOSS_LAND_OPPOSITE`의 `TileId`에는 착지 공격 스킬을 지정한다. 현재 1-4는 `boss_jump_slam`을 사용한다.
- `BOSS_JUMP_TELEGRAPH` 실행 시 현재 보스 위치의 반대편 끝 칸을 `PendingLandingCell`로 고정한다.
- `IsAirborne=true` 동안 보스는 생존 적 턴 순서에는 남지만 Cell 점유와 스킬 타깃에서는 제외된다.
- `BOSS_LAND_OPPOSITE`는 고정된 칸을 다시 계산하지 않는다.
- 착지 칸에 플레이어가 있으면 중앙 방향 1칸으로 밀고, 막혔으면 반대 방향을 시도한다.
- 양쪽이 모두 막히면 착지를 실패 처리하며 두 유닛을 같은 Cell에 두지 않는다.
- 착지 성공 시 같은 `TileId`를 공통 Skill 파이프라인으로 실행한다. 따라서 CSV의 `TargetOffsets`, 피해 Effect, IconRuid가 실제 피해·바닥 범위·머리 위 큐에 함께 반영된다.
- 머쉬맘 점프 묶음은 추가 큐 등록 없이 `공중 예고 1턴 → 착지 1턴`으로 진행한다. 착지 직후 별도 `WAIT`는 없다.
- 공중 상태에서는 실제 보스 Sprite가 숨겨지고, 착지 셀·피해 범위가 바닥에 표시된다. HUD는 착지 칸 위에서 `BattleUnitPresentationComponent.IdleMotionRuid`를 불투명하게 반복 재생해 공중 예고를 표현한다.
- 공격 묶음이 끝나면 `MOVE_AWAY`로 플레이어 반대 방향에 1칸 후퇴한다. 후퇴 칸이 맵 밖이거나 다른 유닛이 점유하면 이동하지 않고 해당 행동을 대기로 소모한다.
- 후퇴는 머쉬맘 패턴에 명시된 행동이며, `큐 없음 → 공통 후퇴` 규칙으로 처리하지 않는다.

## HUD 계약

- 서버 DTO의 `TelegraphKind=BOSS_LANDING`, `LandingCell`, `TargetCells`를 UI가 그대로 표시한다.
- `LandingCell`은 `착지`, 나머지 `TargetCells`는 `피해`로 표시한다.
- UI는 반대편 위치나 스킬 범위를 재계산하지 않는다. 표시와 실제 판정이 다르면 서버 DTO/스킬 데이터를 먼저 확인한다.

## 콘텐츠 수정 범위

콘텐츠 개발자는 `EnemyPatternSteps.csv`에서 위 두 ActionType과 `WAIT`, `EXECUTE_TILE`의 순서만 조합한다.
점프 중 점유·타깃 제외 및 착지 겹침 해소 규칙은 전투 코어 계약이므로 개별 보스 CSV에서 바꾸지 않는다.

## Maker 회귀 항목

1. 머쉬맘 머리 위 큐에 `boss_jump_slam`의 이름과 아이콘이 표시된다.
2. 예고 실행 뒤 실제 머쉬맘 Sprite와 HP는 숨겨지고, 착지 예정 칸 위에 머쉬맘의 대기 모션이 표시된다.
3. 공중 상태에서 플레이어 공격이 머쉬맘을 타깃으로 선택하지 않는다.
4. 바닥에 반대편 `착지` 칸과 스킬의 `피해` 칸이 함께 표시된다.
5. 다음 플레이어 행동 뒤 머쉬맘이 반대편 끝 칸에 나타나며 표시한 범위에 실제 피해를 준다.
6. 착지 칸이 플레이어와 겹치면 중앙 방향으로 1칸 밀린다.
7. 중앙 방향이 막히면 반대 방향으로 밀린다.
8. 착지 뒤 추가 `WAIT` 없이 다음 공격으로 진행한다.
9. 공격 묶음 뒤 플레이어 반대 방향으로 1칸 후퇴하며, 막힌 경우 제자리를 유지한다.
10. 보스 HP가 50% 이하로 내려가 Phase가 바뀌어도 공중/착지 상태가 고립되지 않는다.
