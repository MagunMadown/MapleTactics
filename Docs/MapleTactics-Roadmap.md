# MapleTactics Roadmap

> 마일스톤 범위와 후속 작업의 단일 원본. 현재 항목 상태는 GDD·Phase 문서에서 확인한다.
> Last updated: 2026-10-12

## Vision & release criteria

- Vision: 이동·방향 전환·스킬 큐로 예고 행동에 대응하며 지역·상점 경로를 진행하는 턴제 전술 로그라이크.
- Release criteria: M1 핵심 루프·데이터 오류 차단·반복 실행 계약을 확인하고, 계획된 포인터·체감·실기기·정상 런/운영 검증을 마친다. 구현·데이터 존재만으로 출시 완료를 선언하지 않는다.

## Milestones

| M | Theme | Status |

Phase 0/1에는 검증 대기가 남아 있으며 상세 문서를 유지한다. M1의 통합 유물 상점 양쪽 경로·구매/무구매·다음 전투·새 런은 Maker 기능 검증을 통과했다. Phase 1 P1-SHOP의 실제 포인터·화면 검토와 P0-05 Column/Value 진단 보완은 남아 있다. 후속 마일스톤의 번호·범위·순서는 이번 정리에서 새로 정하지 않았다.

### 후속 지역 진행·상점 Edge

현재 데이터에는 6개 Region·28개 StageMapRoutes 및 상점 전후 노드 경로가 있다. 2026-10-12에는 실제 피해 처리로 진행을 가속한 NORMAL 런에서 양쪽 경로·상점 Edge·해금·합류·각 20전투 기록까지 확인했다. [실행 증거와 검증 제한](../Artifacts/normal-run-validation-20261012/verification.md)을 따른다.

- ✅ 아래쪽 상점→엘리니아 기능 경로 — 실제 UI 이벤트·서버 승인·맵 전환·해금과 반대 경로 잠금 확인. 최종 소스 하단 20전투 진행 완료; 물리 포인터·전술/화면 검증은 별도.
- ✅ 위쪽 상점→커닝시티 기능 경로 — 상단 20전투와 자연 획득 골드 구매 확인. 최종 응답 가드 소스에서도 헤네시스 4전투→첫 상점 구매→커닝시티 승인을 재검증; 물리 포인터·전술/화면 검증은 별도.
- ✅ 커닝시티→페리온, 엘리니아→노틸러스, 페리온/노틸러스→슬리피우드 기능 경로 — 양쪽 실제 해금·상점 방문·반대 경로 잠금·합류·포장마차 중간 보스 이후 발록 최종 보스까지 각 20전투 완료 기록 확인. 진행 가속 조건과 전체 콘텐츠 검증을 구분한다.
- ⬜ 모든 도시·상점 Edge를 같은 공통 데이터/UI 규격으로 추가할 수 있는지 감사하고, 확인된 미구현만 정리한다. 기존 맵/Region 행을 새 이름으로 중복 생성하지 않는다.
- ⬜ 원래 확장 기준의 전체 검증: 각 Region의 독립 전투/보스 콘텐츠, 같은 Region 내부 맵 재사용, NodeId/ShopId/해금 조건·Run 상태 소유권, 데이터 추가만으로 UI 확장. 일부 구현을 전체 완료로 바꾸지 않는다.

`WorldMapFutureRegionButtonComponent`는 `TargetNodeId`가 설정되면 서버의 다음 노드 선택을 요청하고, 빈 값일 때만 `다음 지역 맵 준비 중` 안내를 표시한다. 실제 authoring 바인딩과 정상 경로는 위 검증으로 확인하며, 모든 버튼이 안내만 표시한다고 단정하지 않는다.
